# team-inbox

Místo, kam Stanislav a tenant házejí podklady pro tým - zadání, materiály, inspiraci, screenshoty, klientské vstupy, handoffy od orchestrátora.

Tým si obsah přebírá, čte a kontextualizuje. Nic se odtud nemaže automaticky - inbox je vstupní kanál, ne pracovní složka. Zpracované podklady zůstávají jako audit trail.

Rozpracované a persistentní výstupy patří do `team-outcomes/`, ne sem.
